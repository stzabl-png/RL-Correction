# V5 训练框架总览(Noisy-World RL · 通用部分)

> 2026-08-28 定稿。本文档面向复用者:列出**训练设定、场景设定、以及两种参考驱动体制**。
> Success Tracker(四 Gate + 认证)是逐任务设计件,不在本文范围——Pour17 的实例见
> `tasks/Pour/17/A_Design/L3_Learning/progress.py`(标量规格)与 `REWARD_DOC.md`。

## 一、总架构:三 Prior + 一 Tracker

一条第一人称视频经重建流水线产出三件 **Prior**,任务侧只需再写一个 **Success Tracker**:

| 件 | 内容 | 来源 |
|---|---|---|
| ① 物体轨迹 | 逐帧位姿 + **逐帧双置信度**(conf_pos / conf_rot,0~100) | FoundationPose 重建 + 置信度链路 |
| ② 人手轨迹 | 双臂关节行 + 手指行(与物体轨迹同一时钟轴) | 人手重建 + retarget |
| ③ GraspPose | 抓形模板 + squeeze 收紧层(逐关节 Δq) | Dexonomy 模板链 + thumbfix |
| ④ Success Tracker | 任务成功的阶段机判据(逐任务设计) | 人工设计,判据双版纪律 |

**母带(reference tape)**:全链行 = Approach(机器规划) + 缝1 + 交互段 + 缝2 + Retreat(机器规划)。
交互段的手部参考由**物体轨迹反解 IK** 生成(见 §四),人手行以 `human_*` 列保留供
形状指引。单时钟制:唯一时钟 = 母带行轴,conf/进度经 `frame_of_row` 挂重建帧轴。

## 二、场景设定

- **机器人**:Vega 1P + SharpaWave 双手,固定躯干站姿 USD。**世界指纹纪律**:站姿 USD
  = 世界版本,ckpt 绑定出生世界;每次训练落 `world.json`(含母带 md5、变体、β 剂量、
  USD 路径、obs/act 维度),回放/评测必须回出生世界。
- **物体**:重建网格烘焙碰撞 USD,静置位取母带交互首行;**z 换基**:物体全轨 z 平移
  对齐物理推导的合法静置 z(重建网格 vs 烘焙 USD 的系统差,Pour17 实测 +1.64cm)。
- **传感器**:每手 5 指垫接触力(判据原料);跨侧互撞传感器(D6,远端外壳×远端外壳,
  判力不判距;1-env 回放用 `POUR_NO_D6=1` 规避 PhysX 断言)。
- **物理**:20Hz 控制(decimation=12);阻尼/刚度沿用 pregrasp 配方;无域随机(MVP)。
- **squeeze 前馈剂量**(关键标定结论):握力 = 刚度×压入深度。剂量按**侧**独立:
  重物侧(瓶 0.53kg)β=2.0(零动作实证扛提升+倾倒全程);轻物薄壁侧(杯)β=1.0
  (捏深反被挤飞)。剖面 = 缝1 渐入 → 交互全量 → 缝2 渐出。
  ★深捏会使接触垫数变少(力集中,β2.0 稳态 2 垫)——垫数不是握力代理。

## 三、训练设定

- **动作 58 维** = [右臂7, 左臂7, 右指22, 左指22] **绝对关节目标** = 母带行前馈 + 有界
  残差(绝对锚累积,臂 ±5/8cm 机器/人手两档,指逐关节界)。
  门控:Approach 臂+指全冻(纯放音,规划已是碰撞检查可行解);缝1 起全开;Retreat
  臂开(躲避正业)指冻。
- **观测 503 维**:本体(位置/速度 58×2)+ 双腕位姿速度 26 + 跟踪误差 58 + 残差状态 58
  + 前瞻(1/2/4/8/16 行臂差+档位)75 + 触觉(腕系力+接触)40 + 臂力矩 14 + 上步动作 58
  + **制度量纲 5**(当前行的 w_obj/皮筋宽/rot禁/手门旗)+ 物体块 38 + 进度状态 7 +
  滑移块 8(逐侧滑移量/滑速/垫压/垫数)。critic 特权 12(质量/摩擦/tip力)。
- **PPO**:自研单卡(rl_rebuild),512 env,horizon 32;p(t0) = 0.2+0.6·EMA(终关率)。
- **RSI 渐进解锁**(通用设计):初始出生点仅 t0;**EMA(gate_k) ≥ 0.2 才解锁该 Gate
  出生点**——"Gate 未达,后段 RSI 无意义"(抓不稳时把兵投进交互纯属送死)。
  出生带焊接热身 15 步(物体钳位等手指压实)。
- **通用奖励件**(任务无关部分):
  | 件 | 形式 | 说明 |
  |---|---|---|
  | 行进 | +1/行 earn-only | 时钟门见 §四 |
  | 皮筋 | 分量化连续渐强,截断 −3/步 | 容差按 conf 档;持握换基(抓住后判相对基线增量,消重建系统差的"存在税") |
  | 站位维持费 | +0.05/步 | 抓稳认证前、垫数达标时(消站位零奖励真空) |
  | 握紧反射 | +垫压正差分×min(滑速/1cm,1) | 滑了才有,收得越快奖越大 |
  | 滑移斜坡 | −0.5×(滑移/5cm)² | 滑移死线悬崖前的超线性梯度 |
  | 贴实奖金 | Δ势(距离+力各半) earn-only 棘轮 | **仅第一关后发放**(防站位农耕) |
  | 死线 | 掉落/倒伏/甩飞/滑移/撞桌 −10 终局;互撞 −0.5/步封顶;超时零罚 | 豁免原则:凡参考会路过的状态绝不是死区 |
- **评测纪律**:成功率只认确定性口径(独立 eval 脚本,mu 动作);训练流自带指标无证明力;
  TB 只认挣的(RSI 预置不计);判读针预登记,防事后挑数。

## 四、两种参考驱动体制(核心可复用件)

交互段手部参考统一由**物体轨迹反解 IK** 生成:站位捕获抓变换(增量空间法,
`腕目标[k] = ΔT_obj[k] ∘ 腕FK(站位)`),逐行 ArmIK,手物相对位姿恒定 by construction
——消除"借人手行"带来的手物系统不一致(实测 4~5cm 载高 → 归零)。
人手行不再做绝对位置参考,保留为 `human_*` 列。

置信三档(逐帧,主档 = min(conf_pos, conf_rot) 档):绿 ≥70 / 黄 40~70 / 红 <40。

### 体制 1:P-OBJ(纯物体轨迹 + 自主探索)
- 时钟门:全程双物体贴物轨(5cm/45°);红档只放宽(pos 8cm,rot 禁判);
- 皮筋:pos 3/5/8cm、rot 15°/30°/红禁(按各自 conf 档);
- w_obj ≡ 1,无人手项——低置信区完全交给策略自己探索。

### 体制 2:P-HYB(物体定成败,人手按置信度给"怎么动"的形状指引)
物体轨迹在所有档位定义任务成功与绝对位置底线;人手轨迹全程**不做绝对位置参考**,
只提供轨迹形状指引,权重随置信度滑动(物/手):
- **绿(高置信)= 1.0/0**:只鼓励物体贴物轨——与体制 1 完全相同;
- **黄(中置信)= 0.5/0.5**:物轨开始不准,人手形状参考加入,五五开;
- **红(低置信)= 0.2/0.8**:物轨自身形状已不可信,人手形状主导;但物体绝对位置仍被
  宽皮筋(8cm)+甩飞死线拴在原物轨附近——形状信人手,位置底线还是物体的。
落地形式:形状指引奖 = +0.2 × W_HAND(档) × cos(Δq臂实测, Δq人手行),clamp≥0 只奖不罚;
时钟门双体制统一(绿黄 5cm/45°,红宽物门 8cm、rot 不判)。
手指形状先验同机制可扩展(拧瓶盖类任务的三指扭动 prior 走此通道)。

**选型建议**:低置信区旋转信息重要、或动作由手内操作主导(拧瓶盖)→ P-HYB;
物体轨迹整体可信、任务由物体位姿定义(倒水/搬运)→ 两者对照训练取优。

## 五、移植清单(新任务实例化步骤)

1. 备齐三 Prior(物体轨迹+conf / 人手轨迹 / GraspPose+squeeze),拼母带 v1(人手行版);
2. 标定 squeeze 剂量 β(逐侧零动作探针:提起+关键旋转段能否扛住;剂量窗两端都要测);
3. 物体轨迹反解 IK 重铸交互段 → 母带 v2(含认证行、human_* 列);高速窗(放/砸/翻)
   可做**时间扩张**(物体轨迹细分插值再解 IK);
4. 设计任务 Success Tracker(判据双版:标量规格 + torch 镜像,自检家族:放音/批量一致/
   RSI 点位/合法变体/反向验证);
5. 验收硬闸:零动作播 v2 + 剂量,关键段必须过(过不了的段 = RL 的课,要明确记档);
6. 训练冒烟(短发真训练,验 TB 针全在线 + 世界指纹)后再上算力。
