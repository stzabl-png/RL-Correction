## 2. 今天定位到的**真根因** (有完整证据链)

**参考路径每步跨 1.07cm, 而到位判据的位置窗口只有 1.04cm —— 前馈是从窗口上方
"跨过去"而不是"落进去"。**

| 测量 | 值 | 出处 |
|---|---|---|
| 物理可达精度 | **0.16 cm** | 命令到 IK 解静置 120 步, 关节误差 0.00° |
| 确定性策略最近 | **1.62 cm** (256 env 中位, 极一致) | `diag_arrive_gate` |
| 最近那刻**命令**离目标 | **1.75 cm** | ⟹ **不是跟踪误差** |
| 最近那刻**腕速** | **18.84 cm/s** (判据要 <5) | ⟹ **高速掠过**, 不是停在门口 |
| 退避段参考自身速度 | **21.4 cm/s** (24.6cm / 23 档 × 20Hz) | 与掠过速度吻合 |

**修**: 档位改幂次分布(近密远疏) `d_k = D·(k/(M-1))^2`, M 24→32。
最靠近终点的档距 **1.070cm → 0.026cm**, 折合腕速 **21.4 → 0.5 cm/s**。

## 4. Approach 段的当前设计 (docs/APPROACH_DESIGN.md 为准)

* **起点族**: `û = normalize(GraspPose 手座 − 物体中心)`(radial), `q(d)=IK(gp+d·û)`,
  `D = 1.5×d_g`, 32 档幂次分布。**准入门**: λ 从 0 抬到 2.0, 直接判外壳离桌余量与单调性。
  (轴的选择实测: human 退避时朝桌面去; palm 退 6cm 间隙原地不动; **只有 radial 单调**。)
* **参考路径**: 站姿前缀 60 帧(腕走直线) + 退避 32 档 = **92 帧**, 终点 = GraspPose。
* **课程两段**: `retract_ratio` 0→1 放宽下界; `stance_prob`(far_bias) 0→1 压低上界,
  **=1 时训练分布 == 评测分布**。⚠ 与 `approach_t0_max` **方向相反**。
* **动作 7 维**(只有臂): 接近段 `hand_gate=0`, 手指 6 个通道乘零 = 空转。观测 139。
* **奖励最小集**: align(势差分, 主项) + r_reach(**100**) + arrive + arm_table/table/self_gap
  + hit(硬终止) + imit(参考=退避路径, 权重 6.0) + 小正则。**关掉 13 项**抓取段的。
* **硬终止**: 臂外壳穿桌 / 手碰物体(用户定的底线)。`arm_shell_margin` 1.0→**0.8cm**。
* **公差回退闸**: 慢 EMA 连续 10 epoch 低于历史最好的 70% 才准放松一档(原为瞬时回退)。

## 7. 三条方法教训 (今天用算力换的)

1. **"解释自洽" ≠ "解释正确"**。三个解释都能讲通全部已知现象, 每个都被一次针对性
   测量否掉。要据此改设计前, **先设计一次能证伪它的测量**。
2. **恒 0 / 恒不触发的量, 先怀疑"没被写"再怀疑"值就是 0"**。今天两次栽在这:
   `_fgate_dg` 被覆盖成 None、冒烟里 `if "arm_gap" in _sig` 恒假却打印"✅通过"。
3. **修对了一个真问题 ≠ 修对了当前问题**。误删的课程第二段确实是 bug, 但它不是
   这次 0% 的原因。
