## 2. 相位机 (P0→P2 为 MVP; P3 暂缓)

- **P0 稳抓**: 起步 = 双手摆 GraspPose (纯 RSI, 裁定②), 手指=数据抓形。RL 学握稳:
  判据 = **各自模板参与指**接触 (裁定③, finger_active 机制自动随物体/抓法变) +
  滑动度量连续 K 步小于阈值 → 过闸。
- **P1 跟视频先验** (裁定: 不设人工子目标): P0 过闸后直接跟踪高置信相对 waypoint
  序列 (σ 调权), waypoint 时钟外生推进; **瓶 waypoint 驱动右臂, 杯剖面驱动左腕**。
- **P2 倾倒 (纯几何)**: waypoint 断供, ff 定格, 判据接管: **瓶口**投影落在**杯口**
  圆内(+2cm 容差) 且 瓶倾角 ≥90° 且 保持 10 步 ⟹ 成功。瓶口/杯口位置从**场景资产
  网格**上量 (口沿圆), 不用重建网格。
- P3 回正放回: 暂缓 (waypoint 密集段 90-142 留着)。

## 3. 手内稳定 (防滑) —— 一等公民

- 度量: T_rel(t) = T_wrist⁻¹·T_obj; P0 过闸时快照 T_rel*; slip = (‖Δpos‖, ∠Δrot)。
  双侧都算 (**右瓶左杯**)。
- 奖励: −w_slip·slip 速率; 判负: Δpos>3cm 或 Δrot>25°, fell 照旧;
- **toppled 任务化**: 瓶在手且未判滑时**豁免** fail_tilt (倒水本来就要 113°!);
  杯的护栏 = 偏离数据剖面过远 (剖面峰 58°, 护栏建议 ~80°, 实现时标定)。

## 4. 裁定记录

## 5. ★取数与摆放公约 (2026-08-19 GUI 逐步验证定稿 —— 实现照抄, 不许偏离)

**三个世界, 各管各的:**

| 世界 | 权责 | 禁令 |
|---|---|---|
| 重建世界 (rts/replay npz) | 轨迹与姿态的**唯一来源** (相对量) | 绝对位置/绝对朝向不进场景 |
| 训练场景 (env reset) | 摆放的**唯一来源**: XY 听手、Z 听桌 (obj_rest_z)、姿态=自动摆放(直立开口朝上, **不用重建旋转**) | 不许被重建数据改摆位 |
| 物体网格局部系 (SAM3D 任意 canonical) | —— | **全面禁用**: 局部 z 不是上轴; 训练资产(旧 pour17 网格+0.4516 缩放)与新重建网格系毫不相干, 身体系位移绕错轴 |

**变换公约 (逐条来自踩坑, GUI 三步验证通过):**

1. **全局水平转角 Rz** (唯一允许的旋转对齐): 把重建"杯→瓶"水平方向转到场景
   "杯位→瓶位"方向。全场景一个, 保相对几何; 逐物体旋转 = 拆散相对布局 (左右调换
   事故) —— 禁止。
2. **世界系相对量, 支点=物体自己** (回放与路标同款):
   `R_sim(t) = Rz·[R_rec(t)·R_rec(0)⁻¹]·Rzᵀ · R_rest`
   `p_sim(t) = p_rest + Rz·(p_rec(t) − p_rec(0))`
   性质: t=0 恒等 (物理静置零跳变); 支点在物体自己 (算子绕重建原点转会把物体抡飞
   —— 已踩); 网格系无关 (身体系位移在新旧资产间绕错轴 —— 已踩); 倾角幅度=重建
   原值, 方向经 Rz 指向场景里的对方。
3. **真实上轴标定**: u = R_rec(0)ᵀ·ẑ (首帧静置定标), 倾角 = ∠(R(t)·u, ẑ)。
   局部 z 轴禁止 (SAM3D 系的 z 几乎水平, 之前 33°/54° 全是错口径读数)。
4. **相对 waypoint 的场景化** (P1 监督): 瓶目标位姿 = 上式直接给; 或以杯为参照的
   相对路标 `T_rel(t) = T_杯,sim(t)⁻¹·T_瓶,sim(t)`, 两者等价 (同一 Rz 映射)。
5. **★布局域差 (15.9cm vs 36.3cm) 的处理** —— 待实现时二选一 (open):
   (a) Pour 场景摆位向重建靠拢 (杯瓶距离缩到 ~16cm, 听手约束重验 IK 可达);
   (b) 路标按"杯锚定"重定标 (瓶的相对路标挂在场景杯位上, 位移终点缩放到场景距离)。
   倾倒段几何判据 (瓶口对杯口) 与域差无关, 两方案下不变。

**腕前馈反推链** (P0 过闸后): T_wrist(t) = T_obj,sim(t)·T_rel*⁻¹ (T_rel* = 过闸
快照) → 逐 waypoint IK (种子链式) → 关节样条 = 双臂 ff; 倾倒窗 ff 定格, 纯 RL。

**实现要点**: 底座 = v2 (bimanual_native_env) + S3 关系层; 奖励 = M_grip / waypoint
追踪 (σ 调权) / M_tilt90 / 成功大奖 + slip 罚 + 杯剖面软约束, 失败硬终止; 里程碑
阈值一律派生式 (m1 零余量教训); confidence 只做 60 粗筛+权重, 不做硬门。
