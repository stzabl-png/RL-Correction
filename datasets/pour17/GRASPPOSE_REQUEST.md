**硬约束**:
1. **不许穿桌** —— 物体立在桌上,抓握的手/前臂外壳最低点必须高于桌面(留 ≥1cm 余量);

   接触点**无一落在 elastomer**,而只有 elastomer 有高摩擦。

## 4. 需要的输出格式(与现有训练管线一致)

每个抓握输出一个 `.npz`,键与形状**必须**如下(参照 `tasks/pregrasp/priors/Screw27_body.npz`):

| 键 | 形状 | 含义 |
|---|---|---|
| `grasp` | (29,) | 抓握时的 qpos(Dexonomy 的 `grasp_qpos`,含腕位姿+手指) |
| `squeeze` | (29,) | 再挤压一点的 qpos(用于给出挤压方向/行程) |
| `pregrasp` | (6, 29) | 预抓握轨迹:从张开接近到 `grasp` 的 6 步 |
| `contact_pos` | (K, 3) | 规划接触点,**物体局部坐标系** |
| `contact_normal` | (K, 3) | 对应法向(指向物体外) |
| `contact_centroid` | (3,) | 接触点质心(物体局部系) |
| `canon_rot` | (4,) | 生成该抓握时物体所处的规范姿态 wxyz;若直接用网格原姿态则为 `[1,0,0,0]` |
| `source` | uint8 数组 | 溯源字符串(模板名/物体/日期/参数),`np.frombuffer(s.encode())` 即可 |

**输出放这里**(文件名请照此,训练侧会直接按名引用):

## 5. 已知坑(来自本项目台账,请提前规避)

1. **Dexonomy 接触标定点 vs 我们的力垫有 ~2.5cm 系统差** —— 拧盖任务两次训练全零就死在这:
   模板回放的合拢轨迹从物体旁边掠过,接触梯度恒为零。请确保**合拢过程中接触点真的落在物体表面**,
   而不只是"最终位姿数值上贴合"。
2. **零动作回放要能产生接触** —— 我们的验收口径是:把 `grasp`/`squeeze` 直接回放,
   应当出现多指持续接触力,而不是瞬时点触。
3. **容器类物体的凸分解**要 128 hulls + shrink_wrap,否则杯内腔/瓶肩颈的凹陷会被桥接成
   "幻影壳",手指会被看不见的壳挡住(screw27 实测整瓶被推走)。若你们的合成也用凸分解,请同样处理。
4. 杯是**薄壁空腔**(实心度 0.09),抓在侧壁;瓶当前是**封闭壳**(两端都封,因为视频里瓶盖是拧上的)。
