# RL 训练检查标准: 到多少步看什么、看到什么就改什么

**立场**: 今天(2026-08-16)烧掉的算力里,**绝大部分不是"算法学不会",而是"设定坏了但没人发现"**——
三个自造 bug 让六条 run(>1亿步)全部作废,而每一条都在 TB 上"看起来在训练"。
所以本表把**健全性门**放在最前面,学习判读放在后面。**门没过就别读学习曲线。**

标尺(同一条 clip `Grasp3`,同一台机器量纲):

| 里程碑(TB `success_rate_ema`) | 冠军存档 | CTRL3(人手轨迹起点) |
|---|---|---|
| 1% | 6.5 万步 | 9.8 万 |
| 10% | 22.9 万 | 29.5 万 |
| 25% | **55.7 万** | 665 万 |
| 50% | **134 万** | 918 万 |
| 最终确定性 | **99.99%** | **0.00% @1700万停** |

⟹ **25% 这个点最有判别力**: 冠军 55.7 万, 失败的那条 665 万(慢 12 倍)。

---

## 阶段 0 — 开训前(必过, 不过不许起)

| 检查 | 工具 | 不过怎么办 |
|---|---|---|
| 资产链完整 | `python -m tasks.pregrasp.preflight <clip>` | 补文件; **别靠"起训练看它崩在哪"**——那样一轮只发现一个缺失(实测四轮) |
| 起点合法 | `python -m tasks.pregrasp.smoke_retract ...` | 起点非法 = 每回合从违规态开始, 任务无解 |
| **判据活性** | 冒烟里的"判据活性"段 | ⚠ **恒不触发的检查 = 假通过**。今天栽两次: `_fgate_dg` 被覆盖成 None(门控整段没跑过)、`if "arm_gap" in _sig` 恒假(却打印"✅通过") |
| 场景没变 | diff 启动横幅(`[setup]`/`[replay_grasp]`/`[prior]` 那几行) | 横幅一致才能拿旧成绩当对照; 物体挪了 15cm 时冠军权重评出 0% |
| **枚举全部课程** | 看 `curr/*` 有几条 | ⚠ 少枚举一条就会误判。今天两次说"XX 拉满就是判读点", 都漏了公差那条 |

---

## 阶段 1 — 0 ~ 0.5M 步: **只看"活着没有"**

**不看成功率。** 这一段的成功率没有信息量。

| 指标 | 正常 | 异常 → 动作 |
|---|---|---|
| `diag/*` 全部 | 有非零值在动 | **恒 0** → 先查"是不是没被写"(getattr 默认值覆盖 / `_sig` 还没组装), 别急着解释成"值就是 0" |
| `losses/critic_loss` | 从大值(1~10)快速降到 <0.5 | 不降/发散 → 观测里有 NaN 或量纲爆炸 |
| `term/*` | 有分布, 不是单一项 100% | 某项恒 1 → 那就是唯一失败模式, 先修它 |
| `diag/arm_table_gap_cm` | > `arm_shell_margin` | 恒负 → 摆位/候选不可用, **停训**(台账 §2.20 登记的证伪信号) |
| FPS | 与同机同规模历史一致 | 掉一半 → 查是不是被别的活抢卡 |

---

## 阶段 2 — 0.5M ~ 3M 步: **爬坡期, 看斜率不看绝对值**

| 指标 | 正常 | 异常 → 动作 |
|---|---|---|
| `success_rate_ema` | 单调上行, 3M 前过 10% | 3M 还没到 1% → 对照冠军的 6.5 万, 慢 45 倍以上 = 设定有问题, **别再等** |
| `curr/*` 各条 | 在推进 | 卡住不动 → 它的驱动量(通常是成功率)没起来, 回阶段 1 查 |
| `info/kl` | 在阈值下方波动 | **持续贴阈值** → 信赖域被打满, 策略想大改被按住; 配合 `clip_frac`>0.2 = 不稳定 |
| `losses/entropy` | 缓降 | 陡降 → 过早收敛; **上升** → 策略在往"靠噪声"跑 |

---

## 阶段 3 — 3M 步起: **第一次可信的确定性评测**

⚠ **读确定性评测之前, 先对齐口径**:

```
训练判据 = curr/eps_pos_cm , curr/eps_rot_deg      (课程当前值)
评测判据 = _eps_final                              (最终值, 1.04cm / 2.18°)
```

**两者不同时, 评测成功率与 TB 成功率不可比。** 2026-08-16 实测: 训练练到 1.9cm/7.9°,
评测考 1.04cm/2.18°(朝向差 **3.6 倍**), 于是 TB 35% / 评测 0% —— 这个 0% **不能**
读成"学不会"。

| 情形 | 含义 | 动作 |
|---|---|---|
| 公差课程未收敛 | 评测在考没练过的精度 | **不下结论**, 继续跑; 但要盯公差是否在**倒退** |
| 公差已收敛 且 评测 ≈ TB | 正常 | 继续 |
| 公差已收敛 但 **评测 ≪ TB** | **策略依赖探索噪声**(mu-only 失效) | 降 `init_action_std` / 加熵罚 / 检查是否有"靠抖动蹭过判据"的通路 |
| 公差**震荡或倒退** | 收紧由成功率驱动, 成功率一掉就放回去 ⟹ 卡在局部解 | 改公差课程(放慢/单调化), 或换奖励塑形 |

---

## 阶段 4 — 判"该停了"

`auto_stop` 的两条(默认):
* **达标早退**: 确定性 ≥99% 连续 2 次
* **平台期**: 最佳成功率连续 5 次评测没涨够 1%

⚠ **平台期判据只在 `curriculum_done or curriculum_stalled` 时才计数**。课程一直"推进中"
就永远不会触发 ⟹ **会一路跑到 `--max_agent_steps`**。所以人要自己判:

| 人工叫停的信号(满足 ≥2 条) | |
|---|---|
| 成功率停在某个值 >3M 步没动 | |
| 公差/课程**倒退** | |
| 安全余量被吃(如 `diag/arm_table_gap_cm` 单调逼近 0) | 说明策略在拿安全换指标 |
| 里程碑比同 clip 的已知最好慢 **>10 倍** | 25% 那个点最灵 |

## 各指标的"看到什么就改什么"速查

| 指标 | 病象 | 对应调整 |
|---|---|---|
| `term/timeout` ≈ 1 | 走不到 | 加预算 / 检查每步位移上界(臂 5mm/步)够不够走完距离 |
| `term/table_crash`/`pushed`/`fell` 高 | 撞坏了 | 起点族/摆放问题, 回阶段 0 |
| `diag/arm_table_gap_cm` → 0 | 贴着桌子换指标 | 加 `w_arm_table` 或抬 `arm_shell_margin` |
| `grasp/pads_now` 恒 0 | 够不到 | **零动作合拢基线**(`diag_fgate`)看是不是候选本身抓不住 |
| `losses/entropy` 上升 | 靠噪声 | 熵罚 / 降 sigma |
| `info/clip_frac` > 0.2 持续 | 更新被裁太多 | 降 lr 或放宽 kl |
| `losses/critic_loss` 不降 | 价值学不动 | 观测量纲 / NaN |
| `ep_rew/<某项>` 独大 | 奖励被单项主导 | 查权重, 尤其非势函数项(会被刷分) |

---

## 三条今天用血换的铁律

1. **恒 0 / 恒不触发的量, 先怀疑"没被写", 再怀疑"值就是 0"。**
2. **读任何评测前, 先枚举全部课程的当前值**, 确认评测口径与训练口径一致。
3. **改共享参数前 grep 它的全部消费方, 特别是评测那一侧。**
   `approach_t0_max` 被课程和评测共用且语义相反, 改一处就把评测变成"空降到终点"。
