## 3. 机制：为什么 B 行、A 不行

### 3.1 课程**有**回退，不是棘轮（这条我一开始讲错过，别再传错）

`tasks/pregrasp/train.py:118-137`：

```python
self._ar_slow = 0.995 * self._ar_slow + 0.005 * float(ar)   # arrive_rate 的慢 EMA
g = min(self._ar_slow / cfg.curr_arrive_target, 1.0)        # 0→1 的课程进度
cfg.eps_pos = max(cfg.eps_pos0 + (ep_f - cfg.eps_pos0) * g, # 目标值(可升可降)
                  cfg.eps_pos - c * cfg.eps_pos0)           # 限速项(只限收紧速度)
```

第一项随 `g` 下降而**变大** → `max` 会选它 → **阈值会放回去**。B 在 10~11M 的深坑里
阈值从 2.29 自动放回 2.41、模仿罚从 0.36 退回 0.30，就是靠这个爬出来的。
限速项 `- c*eps_pos0` 只约束**收紧**速度，不约束放松。

**A 为什么没得救**：A 的 `sr/from_grasp` 在 **3.5M 步**就掉到 0，那时课程一动没动
（阈值恒 3.00）。所以 A 的病根**不是课程**，是 `kl 0.05` 的大步长把已经学会的抓取
能力直接冲掉了。课程救不了一个已经死掉的技能。

### 3.2 `kl 0.05 → 0.02` 为什么是决定性的

回合有两个起步分支（`direct_grasp_prob`，初值 0.5）：

```
① 直接抓取起步 —— 手已在 GraspPose 上, 误差≈0   ← 抓取技能的训练数据
② 接近起步    —— 从人手轨迹飞过去              ← 早期几乎全失败
```

**同一张网络**。`kl 0.05` 允许的策略更新步长太大，②那一半持续失败的梯度会把①
学到的抓取行为**直接覆盖掉**（灾难性遗忘）。`kl 0.02` 把步长压小，两个技能得以共存。

这也说明**"抓取被脏起点污染"这个解释是次要的** —— A 在 0~4.5M 期间到位率恒 0，
**根本没有任何接近回合进过抓取段**，抓取照样从 0.25 掉到 0.00。是梯度淹没，不是数据污染。

### 3.3 阈值必须放松（E 的贡献）

E 锁死 `eps=1.04cm/2.18°`，11M 步到位率恒 0。可行性课程（先放到 3cm/15° 再收）
是接近段能启动的**必要条件**。

|---|---|---|---|
| **N1 复现** | 只换种子（`--seed 7`） | **B 是不是运气？** 那个 1M 步的深坑换种子还能爬出来吗 | 7 |

### 4.3 预注册判据

- **主**：`sr/from_approach ≥ 0.3` **且** `curr/eps_pos_cm ≤ 1.5`，持续 2M 步
- **次**（回归探针）：`sr/from_grasp ≥ 0.8` —— 不许为接近牺牲抓取
- **判死**：15M 步仍 `sr/from_approach < 0.05`

**证伪信号**：
- N1 也起飞 ⟹ B 可复现，配置可以固化进默认值

- N3 有效 ⟹ 深坑变浅/变短；若深坑反而更深，说明快 EMA 让课程来回震荡，回滚

## 5. 操作须知（踩过的坑）

1. **`RL_ISAAC_NO_GUARD=1`** —— 见 §1，多卡机必加。
2. **判断一条 run 有没有 `--approach`：看 TB 的 `curr/*` 标量或 `/proc/<pid>/cmdline`，
   不要 grep 日志。** 日志经 `tee` 带 `\r`，`grep -E "^\[approach\]"` 的 `^` 锚点会失效。
3. **成功率只认 `sr/from_approach`**（端到端）和 `sr/from_grasp`（纯抓取）。
   `success_rate_ema` 是两个分支的混合，会误导。
4. **错峰启动**：等前一条进了训练循环再起下一条，同时并发会撞 futex 冻住。
5. `ls | tail` 是字典序，取 ckpt 用 `last.pth`。
6. 杀 Isaac 后等 10s 再起下一个。

### 读 TensorBoard 的脚本（`/tmp/rep.py` 是临时的，会没）

```python
from tensorboard.backend.event_processing import event_accumulator as EA
import numpy as np, glob, sys
for d in sorted(glob.glob(sys.argv[1])):
    a = EA.EventAccumulator(d, size_guidance={"scalars": 200000}); a.Reload()
    ks = a.Tags()["scalars"]
    f = lambda k, n=50: (np.mean([x.value for x in a.Scalars(k)[-n:]]) if k in ks else float("nan"))
    st = a.Scalars("success_rate_ema")[-1].step / 1e6
    print(f"{d.split('/')[1]:20s} {st:6.2f}M  arrive {f('approach/arrive_rate'):.3f}  "
          f"grasp {f('sr/from_grasp'):.3f}  END2END {f('sr/from_approach'):.3f}  "
          f"eps {f('curr/eps_pos_cm'):.2f}cm  imit {f('curr/w_imit_ramp'):.2f}")
```
