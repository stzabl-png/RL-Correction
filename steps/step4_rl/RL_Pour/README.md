## 二、参考轨迹 carry4a(构建器 `tasks/pour/build_carry_ref4.py`)

核心思想:**手当里程计,物体当路标,置信度决定谁在哪一段说话**。

1. **手锚融合**:人手腕弧(EgoDex ARKit,conf=1.0、窗内逐帧 ≤9.1°/1.0cm)当
   里程计;物体高置信帧(conf≥60 ∧ 真测量 ∧ NIS<5,锚距 ≥10 帧)当路标锚;
   锚间播人手相对弧,闭合误差**后段加权**回收(倒水弧中段保真)。
   依据:旧参考(虚构物体反推)在沙漠窗腕姿态错 83.5°(p50)。
2. **桌面净空钳制**:手最低点(伸直指最坏情况)≥ 桌面+2cm,平滑抬升。
3. **窗内物体契约 = 手隐含位姿**(刚握传播):治重建"抢跑"(RTS 尖刺提前倾,
   32/103 行超时钟门 20° 容差会卡死时钟);副产物:瓶杯网格间隙 3.3→7.4cm。
4. **撤退截除**(end_frame=124):腕速仲裁实锤帧 128-136 为松手撤退、杯尾段
   conf=0 的"运动"是虚构。
5. **参考辅助(`--mouth_assist 0.05`)★破局关键**:倾角 ≥60° 的窗内行把隐含
   瓶口水平收向杯口(60°/12cm → 93°+/5cm,5 行平滑)。还的是重定向丢失的
   demo 几何(人手 demo 实测瓶口-杯口 4cm@109°,经抓姿/场景锚定搬运后只剩
   ~11cm)——非虚构外力,离线可验证,无退火问题。
6. 8°/行转速限幅重采样(物体+腕联合细分);自由窗行号 `free_lo/hi` 写进 npz,
   train/record 自动接管(时间轴随构建变,严禁硬编码)。

产物体检(必须全绿才可训):IK 误差 max 0.5cm / 手最低-桌面 ≥1.9cm 穿桌 0 /
瓶杯间隙 ≥7.4cm / 关节步长 ≤8°/行 / 时钟一致性(契约 vs 手隐含倾角)≤2.3° /
参考自带同框行(≥93° 且口距 ≤5cm)29 个。

## 三、Reward 设计

### 正项

| 项 | 权重 | 机制 |
|---|---|---|
| `prog_pot` | 40(全程总额封顶) | 全局进度势,telescoping。**自由段进度 = 联合乘积棘轮(v9J)**:每步 `min(倾角/93°,1) × clamp((25cm−口距)/(25−6),0,1)` 乘积的历史最大值。q=1 ⟺ 判据同刻达成(差 hold)。连续无悬崖;45°×半对齐给约半率 = 自带课程 |
| `mouth_pot` | 60 | 自由段口对口净缩短差分(telescoping,不可刷) |
| `tilt_pot` | 5 | 自由段倾角势差分(±0.1/步 clamp) |
| `ms_tilt` | +2.0 ×3 | 倾角 30/60/90° 一次性里程碑 |
| `ms_pos` | 一次性 | 高置信帧里程碑 |
| `pour_ms` | **+10** | ★ 判据达成一次性(同时成功终止,v6"不做撤离恢复") |
| `frame_adv` | 逐行小粮 | 可信段贴轨推进;受 `grip_prog_gate 20` 门控(抓稳粮须伴随进度,治挂机) |
| `pads_cent_cand` | 向心 0.05/步 + candidate +5 + 垫接触 0.5/0.02 | v5 稳抓链 |

### 负项

`slip_step`(滑移连续梯度)/ `slip_pen`(滑移事件)/ `cross_pen`(物物、手手
5mm 纯碰撞口径)/ `act_reg`(微)。

### 判负与终止(不走 reward 通道)

| 闸 | 阈值 |
|---|---|
| 滑移死线 | 8cm / 60°(相对抓握快照,v5) |
| 跟丢 `carry_lost_m` | **5cm**(可信段;自由段挂起)——64env 确定性实测:成功回合可信段峰 max=5.0cm,误杀 0% |
| 偏轨硬闸 `dev_reset_m` | 30cm 全程无条件——成功回合全程峰 24-26cm 是倒水必经之路,15cm 会误杀 100%,实测裁定维持 |
| 启动限期 | 60 步 |
| 撞桌 `table_fail` | 手部 body 触桌即终止(真机红线) |

### 自由段机制(v8 遗产,全保留)

`ff_play`:窗内臂前馈续播,时钟按倾角剖面 ±20° 行进门推进;位置门/跟丢判挂起。
`ff_pull 0`:回拉锚显式关闭(v8D 无锚动力学口径,新训练必须显式给,默认 0.08 是活的)。

## 五、方法论结论(本任务两条硬教训)

1. **奖励结构必须与成功判据同构,且"同一时刻"也要写进结构**:倾角/对齐双棘轮
   各记历史最好值可被"先倾后凑"分时刷穿(13M 实测:圈内占时 10% 而同框步=0);
   联合乘积棘轮修复后 0.3M 内首 ★。
2. **同构的奖励 + 示范的路径,缺一不可**:纯棘轮线(v9A 对照)4M 步 ★=0;
   加参考辅助后一个 epoch 内首响。结构把钱挂对地方,辅助弧领着探索够到钱。
