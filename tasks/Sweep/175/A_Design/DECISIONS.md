- 80 (conf 95): 簸箕无把手, 扫把疑似截断 (尺度口径 ③≫①, 仅 3 可信帧)。

另: 逐帧 "trustworthy" 标记在所有 take 的扫把上都偏严 (408 自己也只有 0.27), 不作依据。

## 5. 第一轮造带 (23:27~23:38 UTC) 与 "过簸箕抬升" 规则的冲突
造带本身干净: 440 行 @20Hz, 逐行 ≤7.80mm/3.42°, 两臂 IK 中位 0.00/0.01cm max 0.02cm, 关节单步 ≤5.75°; 转格式 (人手臂 IK 0.01cm) → `sweep175_sweep2fmt_v0.npz` (1b57f364)。
但 `stroke_scan.py`: **刷毛最低点离桌中位 5.35cm** (范围 −0.1~8.2), 刷面心簸箕系 y 中位 5.5cm; 408 同口径是 −0.1cm / 0.7cm。
不是数据: 原始配准轨里 "扫把最低点 − 簸箕最低点" 175 中位 3.8cm vs 408 3.2cm, 同级。
是构带器 2026-09-12 为 408 加的规则 (`[lift]`: 扫把头俯视足迹与簸箕足迹距离 <5cm 就把扫把抬到**簸箕整体最高点**+5mm)。408 的扫把不进簸箕,
这条只影响擦边行; 175 的扫把有 31% 行在口内 (人就是伸进斗里扫), 被整段抬到斗壁顶上, 方块碰不到。
修: `build_reference.py --lift_mode local` (默认 global = 原行为, 408 不受影响): 参照面 = 扫把头足迹 (俯视凸包外扩 1cm) 下方簸箕顶点的最高 z ——
足迹在斗底 → 贴斗底 +5mm; 压到斗壁/柄 → 抬到壁顶; 未重叠 → band 内最近一圈顶点, smoothstep 过渡。第二轮 (`FMT_TAG=v1`) 跑中。
第二轮 (`--lift_mode local` 第一版, 头部凸包外扩 1cm 内顶点最高 z): 仍抬 (最大 82mm, 94.7% 行受影响) —— 头长 12cm 横跨 14cm 斗, 凸包总碰到沿。作废。
第三轮 (刷毛点正下方 6mm 内顶点最高 z + 5mm; 无重叠按 band 过渡): `sweep175_sweep2fmt_v2.npz` (2b32672c) 刷毛离桌 全带 4.0 / 口内 5.0 / 口外 3.3cm —— 还是高。
量化后发现三件事 (数据在 §5 末):
  ① r2 簸箕网格的斗区 (|x|<7.6, z −4~5.7) 顶点 y p50 0.2 / p90 0.8 / max 1.5cm —— **是浅盘, 没有 3cm 的壁** (spec 里 3cm 高的 side 盒是保守碰撞体);
  ② 刷毛在斗区的行 (157 行) x 跨度中位 [−4.8, 5.5]cm, 超出 ±7.1 的只有 7 行, 需要横移 中位 0 / max 0.9cm —— **不需要横向居中**;
  ③ 口内行刷毛最低点在簸箕系 y 中位 1.6cm (斗底顶面 +0.5) —— 斗内其实只高出斗底 1.1cm, "离桌 5cm" 是簸箕倾角 11.7° 的投影;
     真正的问题在**口外**: 口前 5cm 带内被预抬到沿高 (3~4.7cm), 桌上的 2.5cm 方块从刷毛底下漏过去 —— 408 v3 同段是 −0.1cm 贴桌。
  另: 175 的口沿离桌中位 1.64cm (范围 0.6~3.4), 与 408 (1.50cm) 同级, 不是新问题。
第四轮规则 (`--lift_rim_max_mm 10`, 跑中): 参照面只取簸箕局部 y ≤ 1cm 的顶点 (斗底/斜坡/低沿; 刷毛是软的, 允许压过沿), 刷毛下方没有簸箕面就贴桌不预抬 (台阶由细分吸收)。
第四轮 (rim 过滤 + 不预抬) 造带过了展宽 (470 行, 逐行 ≤7.94mm/3.39°) 但被第五道闸拦下: "两物体最小间距 +0.36mm < 2.0mm (行 112)"。
这道闸是 408 的语义 (扫把不该碰簸箕); 175 的动作就是刷毛贴着斗底/斜坡进斗, 两物**接触**是设计, 只要不穿插 (间距 ≥ 0)。
⇒ local 模式发车参数定为 `--min_obj_gap_mm 0` (允许接触, 不允许穿插); 第五轮跑中。
第五轮 (`--min_obj_gap_mm 0`) 造出 470 行 (894d3609), 但刷毛离桌 口外 2.84 / 口内 5.04cm, 口内行只剩 27 —— 因为簸箕本身是**斜的**:
两条母带的簸箕都是 抬柄 10° (口比柄低) + **横滚 ~7°** (左前角是最低点 0.3cm, 右口角 2.4~2.5cm; 408 v3 完全一样: 0.69/2.37cm), "跟随口沿面"就等于抬到 2~4cm。
★ 关键对照: **408 v3 母带口内刷毛也是 −0.1cm (全程压桌, 没有任何抬升)**, 零动作 17/32 扫入成功 —— 刷子与簸箕的接触交给物理
(刷毛体压进斗底 2~3cm, PhysX 把焊在臂上的扫把顶上斗沿, 臂 PD 让步), 这是唯一被实测验证过的扫入配方。
⇒ 175 定为 **`--lift_mode none --min_obj_gap_mm -1`** (与 408 v3 同款: 不抬、不设间距闸), 第六轮 (`FMT_TAG=v4`) 跑中。local 模式保留备用, 不用。
第六轮 `--lift_mode none --min_obj_gap_mm -1` (2026-09-14 00:11~00:22 UTC): `sweep175_reference_v3.npz` 433 行 → `sweep175_sweep2fmt_v4.npz`;
刷毛离桌 全带 −0.10 / 口内 −0.04 / 口外 −0.10cm —— 与 408 v3 同款 (408 v3 口内穿插深度 中位 2.9cm p90 4.2cm, 物理接住了)。
朝口段 (刷面心): 46~78 (z 13.1→6.9, x −2.3→−3.7) / 145~174 (11.2→6.2, x −7→−4.9) / 328~344 (5.4→2.6, 过口沿, x≈−6)。
