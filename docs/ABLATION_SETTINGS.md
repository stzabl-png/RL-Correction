## 1. 成功判据:只用绝对量

**教训(L5-32,数据坐实)**:任何**读参考轨迹**的判据都不能跨臂比较——
门宽随置信档变(base 有红档 8cm、flat 没有),六条臂用的不是同一把尺;
而且旧的 3D 距离口径在确定性回放下 **0.998 无条件通过**(策略学会"横杵在旁边")。

现行主判据(全部只读 物体位姿 + rest=母带第0帧):
```
G3_pour = 倾角>=90° ∧ 水平距<=R_a+R_b(圆盘相交) ∧ dz∈[0,8cm]   连续25步
placed  = 各物体 距rest<=3cm ∧ 倾角<=15°                        连续15步
success = G3_pour ∧ placed        (TB: sr_t0/success, 只认 t0 出生口径)
```

**换任务要重量的**:
- `R_a+R_b` 从 `scene_layout.json` 的 `extent_cm` 现算(倒水=瓶口杯口圆盘相交;
  别的任务换成对应的"功能几何",原则:**判据描述物理上任务完成的几何,而不是
  离参考多近**)。
- **可达性预检(铁则,防 L5-27)**:母带自身必须连续满足判据 >= HOLD 步。
  一行脚本扫四条母带,见 `selftest_pour_criterion.py` ⑦。
- 判据常量全部进 `criteria_items()` 白名单 → `criteria.digest` 变 → 老 ckpt 拒跑。
  **数字自动扫描**已改为从白名单派生(别再手写清单,L5-32.8 漏过 11 项)。

## 3. 两个绝对奖励整形 (earn-only 棘轮) —— L5-33 新增

设计规则(三条都有自检兜底,`selftest_reward_shaping.py`):
1. **只读绝对量**(物体位姿/rest/接触),一个字不读参考轨迹 → 六条臂同尺;
2. **earn-only 棘轮**:只为势能新高付钱,来回晃不挣钱;
3. **播种步不付钱**:gate 首次打开那步只记基线,否则把"达成前就有的进度"白送。

```
placed 整形 (POUR_PLACE_SHAPE=1):
  φ = 0.5(1-距rest/0.35) + 0.5(1-倾角/90°),  ×6.0, gate: g3∧~placed
出水口入接水口 (POUR_MOUTH_BONUS=1):
  ψ = 1 - 口对口水平距/0.12,  ×4.0, gate: g2 ∧ 倾角>=45° ∧ **两物体无接触**
  ("不碰撞"的落地 = 接触那步棘轮冻结不付钱; collide 罚照扣)
```
TB 曲线 `ep_rew/place` / `ep_rew/mouth` 直接可见付了多少钱。

## 4. 母带变体的生成 (build_ref_v5.py)

| 变体 | 生成旗 | 说明 |
|---|---|---|
| 无conf | `POUR_REF_NOCONF=1` | 平滑不用置信度挑锚点 |
| 带噪 | `POUR_REF_NOISE_MULT=N POUR_REF_JOINT_SMOOTH=1` | **方案C**: 物体轨迹保持带噪(消融本体),IK 后只平滑关节列(轻窗9+抓握段重窗迭代) |

噪声幅度 **N 是实测残差的倍数,不拍脑袋**:在真重建段(`source==1`)用 SavGol 平滑
残差量出该任务的噪声底(倒水任务:朝向 瓶7.03°/杯5.16°,位置被上游平滑过不可标定)。
**第 0 行永不加噪**——它是 `rest`,动了它判据就不同尺。

**五道出厂检查**(全过才写盘,md5 进指纹):
① 关节连续性(P95<8°,最大<25°) ② 峰值保全(任务特征损失<5%)
③ IK 精度(<1cm) ④ 末态-判据一致性 ⑤ **抓握段跳变 P95<=残差界**
(第⑤是 L5-33 补的——第一版噪声母带就是抓握段 65% 行超界,两条线白跑 13M 步)。

## 5. 运行时消融旗的接线纪律

每加一个旗,四件配套缺一不可(踩过的坑全在台账):
1. **旗进 `world_fingerprint.CRITICAL`**(digest 抓不到奖励/权重类改动,必须单列);
2. **世界门自检加"该红"用例**(`selftest_world_gate.py` 现有 ⑭ 条);
3. **行为级自检**:验"开旗后每一项下游都变了"+"**关旗与基线逐位一致**"
   (旗最常见的死法是接上了但某一项没跟着变,以及污染了别的臂);
4. 台账写死**判读预置**(什么曲线算证实/证伪),出数后不许改。

## 6. 发射与对照纪律

- **2×2 主消融全放同一台机器**。机器对照实测 `cert_pass` 机器差 +0.25,
  **大于** seed 差——跨机比较不是免费的(L5-32.14)。
- **鉴别实验先行**:一条线死了,先"同机同配置只换 seed"(6M 就够,死亡都在 3~4M),
  再谈机制。本项目在这上面连错三次(先有故事再找证据,L5-32.19)。
- 发射脚本模板 `run_ab3.sh`:`$1=GPU $2=代号 $3=seed $4=VARIANT $5=母带 $6=CONF_FLAT
  $7=ARM_FREE`;启动横幅 + `world.json` 指纹是唯一权威记录,发完必须逐项核对。
- 评测只认 `eval_pour.py` 确定性口径;训练 TB 的 sr 是高估(c0 脚手架+长度偏置)。

## 7. 换任务迁移清单

1. 量物体几何(`extent_cm`)→ 定圆盘相交门 → **跑可达性预检**
2. 量该任务重建的噪声底(静置段/真重建段 SavGol 残差)→ 定 noise 1×/3×
3. 造四条母带(base / noconf / noise1xC / noise3xC),五道出厂检查全过
4. 判据换绝对量,digest 变更 → 全部自检过 → 三台 md5 一致
5. 发射:同机 2×2 + noise 两条;每条指纹逐项核对
6. 判读预置写进台账**再**开跑
