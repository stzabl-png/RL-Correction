## 〇、体制总纲

- **分工**（2026-08-29 用户确认）：cuRobo 只管机器段（Approach 站姿→站位 /
  Retreat 收尾→站姿，残差冻结照谱）；**缝1 起的整个交互段 = RL**，参考 =
  置信度物体轨迹 + 置信度人手轨迹。拧盖动作没有任何"照谱"成分：驱动增益要求
  真实指尖接触，r_screw 奖真实转角，G3 要求物理 detach。
- **参考层**：母带 `<clip>/reference_v1.npz`（离线）→ v2（Isaac 内物体轨迹反解
  IK 重铸 + 认证行）。obj_0=瓶（左手），obj_1=盖（右手）。交互段臂参考由物体
  轨迹推导——本批人手**腕平移是静态填充死数据**（clip32：腕 <0.6cm/盖 66cm），
  人手行只出**手指形状**与逐帧置信度。
- **双变体**：`POUR_VARIANT=HYB`（默认；置信门控 + 指形指引）/ `OBJ`（纯物轨消融）。
- **置信度主档** tmix = min(瓶,盖)×min(pos,rot)——短板决定参考可信度。
- **squeeze 剂量**：βL=2.0（左手瓶，Screw27_body 层，待 probe_beta 复标）；
  βR=0（盖侧设定 B 无 prior，三指精捏交给人手指流+残差）。

## 三、动作/观测契约（58/507）

- 动作 58 绝对关节目标；Approach 臂+指全冻，缝1 起全开，Retreat 臂开指冻。
- 观测 507 = 框架 503（物体块换 [盖-座差 3 + 瓶倾角 1] 语义，维数不变）+
  **螺旋块 4**：[screw_frac, released, n_triad/3, drive_gain]。
- 螺旋驱动（对策略可见亦可感）：gain = 无接触0 / 有接触 max(n_triad,1)/3，
  n_triad 只数拇/食/中（U34+U39）；ω 上限 2.0 rad/s；阻尼 0.9/子步。

## 四、结构原则（承框架 + 旧台账学费）

1. 凡参考会路过的状态绝不是死区；
2. 密集项全部有界（截断/棘轮/封顶）；**完成的一次性收益必须 > 放弃的剩余年金**
   （U29 系三次尸检：任何策略可影响的衰减计数边界都会诱发回避——本实例不用衰减，
   靠 G3+G4+r_screw 的势结构 + placed 终局）；
3. TB 只认挣的（RSI 预置不计）；分母为 0 发 NaN 不发 0（L5-17）；
4. 计酬点名手指身份（拇指必须在接触集）在螺纹**驱动侧**实现（分级增益），
   不再靠奖励加档翻山谷（pk22 教训）。
