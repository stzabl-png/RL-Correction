# 停用的模板 (2026-08-15 用户裁定)

移到这里而不是删除 —— 这些资产未入 git, 本仓库也没有可写远端, 删了不可逆。
要恢复直接 mv 回上级目录即可。

| 模板 | 组 | 停用理由 |
|---|---|---|
| 23_Adduction_Grip  | index+middle (无拇指)              | 无拇指对生, 抓不稳 |
| 2_Small_Diameter   | index+middle+ring+pinky+palm (无拇指) | 同上 |
| 16_Lateral         | thumb+index                        | 侧捏(钥匙式), 对桌面物体不实用 |
| 25_Lateral_Tripod  | thumb+index+middle                 | 同上 |
| 20_Writing_Tripod  | thumb+index+middle+palm            | 握笔式, 对桌面物体不实用 |

⚠ 2_Small_Diameter 在**瓶子**上曾是第一名(pour/17 右手)。停用它是用户按抓型实用性裁定的,
不是数据结论 —— 如果后续瓶类物体产量变差, 优先检查是不是这条。
