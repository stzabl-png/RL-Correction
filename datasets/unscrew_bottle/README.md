|---|---|

| `poseqa/` | 体检报告快照：rts（平滑轨迹+σ）/ cc（CoTracker）/ pose_audit_take.json |
| `contact/expected_area_*.npz` | affordance 接触热区（物体表面 60k 点 + 接触频率） |
| `contact/affordance_*.png` | 热力图可视化（3 视角 + 投回视频帧） |
| `conf_*.mp4` | 可信度叠加视频（物体轮廓 + 手骨架 + 分数带） |
| `recon_render_*.mp4` | 纯重建渲染（重建相机看双手+物体，"RL 眼中的场景"） |
| `outputs_manifest.json` | 自描述清单：有什么、什么版本、走的哪条路线 |
| `masks/` | 逐帧物体 mask + 手 mask |

## 消费须知

1. **逐帧可信一律读 `object_valid_measured.npz`**，`world_fused.object_valid_all` 是跟踪层面标志，不含质量信息；
2. 手部质量读 `hand_confidence.npz`（conf 70 ≈ 45mm 误差，100 ≈ 20mm）；
3. σ（滤波不确定度）在 `poseqa/rts_*.npz`；
4. 先看 `outputs_manifest.json` 再动手，别猜目录。
