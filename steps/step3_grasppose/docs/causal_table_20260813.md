## 判读

1. **价值主形态是"使能"而非提率**: 大物体(notebook/box)上通用模板力封闭全灭、零出货,
   选择器给的包握族是唯一出路 —— 从 0 到 1, 不是 41%→52%。
2. **接触口径近饱和**(100% vs 96%): 能过力封闭 QP 的抓取几乎必然接触稳定, 所以这个口径
   区分不出模板优劣; 它的用处是证明 lift 失败源于执行层(质量/摩擦/力控)而非模板层。
3. **两个口径的定式**: contact = 模板选择器的公平考卷; lift = RL 入口筛。
   两者的落差正是 RL 修正该赚的空间(scissors 接触满分、提举 10%)。
4. scissors 提举双低 + 接触双满分 = 提举判据对薄物体过苛, 非模板之罪。
